# Case Background: Programming Language Debate

## Context
A software development team must choose between Python and Rust for a new high-performance data processing system.

## Requirements
- Process 1 million records per second
- Must be maintainable by a team of 5 developers
- 6-month development timeline
- System will run for 5+ years in production

## Constraints
- Team has 3 Python experts and 2 developers learning Rust
- Existing tooling is Python-based
- Performance is critical for business requirements
